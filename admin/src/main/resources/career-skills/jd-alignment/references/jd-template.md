# 典型 Java 后端 JD 示例

## 岗位要求
1. 了解 LLM 服务、Agent 应用、MCP/A2A 和 Python 优先；
2. 3 年以上后端开发经验，掌握 Java/Golang/Python/C/C++ 等至少一种语言；
3. 熟悉网络编程和多线程编程，对 TCP/IP/HTTP 等协议有理解；
4. 熟悉数据库技术，熟练编写 SQL，熟悉 Redis、MongoDB、Elasticsearch 等 NoSQL；
5. 熟悉常用设计模式，有较强架构能力和良好代码规范；
6. 熟悉分布式缓存、消息中间件、负载均衡、连接池等中间件和分布式方案；
7. 熟悉容器、K8S、ServiceMesh 相关技术；
8. 具备复杂问题分析能力、学习能力、沟通能力和团队协同能力。

## 岗位职责
1. 负责 AI 应用算法服务的开发和维护，完成从需求到上线的项目周期工作；
2. 负责构建高可靠、高可用、高可扩展的分布式 AI 大模型与 AI Agent 服务。
